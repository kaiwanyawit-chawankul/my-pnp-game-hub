GAMEPLAY RULES & MECHANICS

1 Solo Player • 20-30 Mins • Shared Action Dice Pool • Multi-Threat Checks

HOW TO WIN

Harvest 3 DIRECTIVES from locations (like Sub-Basement Vault LOC 04 or Sector 4 Gate LOC 06) and survive before the global Threat Track reaches 10!

OVERRUN THRESHOLD (CAP = 3) & RESET

• Threat Capacity increased to 3: A location overruns only when reaching 3 Threat Tokens.
• Organic Miller Reset: Assigning Miller to Sector 4 Gate exposes him to Catastrophic Breach (2 Wounds), killing him and triggering a 1-time Temporal Reset!

CORE GAMEPLAY MECHANICS

1. SHARED ACTION DICE POOL At the start of each turn, 4 shared action dice are rolled. Assigned operatives draw from this pool as their base check values.
2. MULTI-THREAT HAZARD CHECKS If a location has multiple Threat Tokens, operatives must perform a separate Hazard Check for EVERY Threat Token present (<3 = Wound).
3. CATASTROPHIC BREACH AT SECTOR 4 GATE Sector 4 Gate features a Catastrophic Breach Attack dealing 2 instant wounds. Use this strategically with Miller to activate his 1-time Temporal Loop Reset into Loop 2 (+1 Knowledge Boost).
